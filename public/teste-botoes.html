✅ Checklist de Visibilidade

Se você NÃO vê os botões acima:

  1. Pressione Ctrl + Shift + Delete e limpe o cache
  2. Pressione F5 ou Ctrl + F5 para recarregar
  3. Pressione F12 → Aba Console → Veja se há erros em vermelho
  4. Pressione F12 → Aba Network → Recarregue → Procure style.css → Veja se status é 200

Se você VÊ os botões aqui mas NÃO vê em /equipamentos:

  • O problema pode ser JavaScript bloqueando a renderização
  • Ou há um erro de CSS específico na página de equipamentos
  • Abra o DevTools (F12) e compare esta página com /equipamentos
